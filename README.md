# Steam Design Tools

A free web-based tool for previewing your Steam Profile Showcase. Upload your artwork to preview how it will appear on your profile, with automatic background detection and image cropping — plus additional utilities for uploading long images to Steam.

Built with Vue 3 + TypeScript + Vite, deployed on Cloudflare Pages.

## Project Setup

```sh
pnpm install
```

### Development

```sh
pnpm dev
```

### Build

```sh
pnpm build
```
